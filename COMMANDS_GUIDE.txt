STEP 0: Python Environment Setup
--------------------------------------------------------------------------------
Command:
  python --version

Why we use it:
  Verifies your Python installation (Python 3.13 with PyTorch, Transformers,
  Datasets, Plotly, and Streamlit).
Note:
  If you are using a virtual environment, activate it first (e.g., .\.venv\Scripts\Activate.ps1).
  If using system Python, run the commands below directly.


STEP 1: Run All Unit Tests (Code Health Check)
--------------------------------------------------------------------------------
Command:
  python -m unittest discover -s tests -p "test_*.py"

Why we use it:
  Verifies that all 31 system modules (localization, causal validator,
  parameter controller, PPO controller, live environments) pass cleanly.
Do you run it every time?:
  NO — Run when modifying code or verifying system integrity before presentations.


STEP 2: Run the CASU Master Unlearning Pipeline
--------------------------------------------------------------------------------
Commands:
  # Option A: Fast Local CPU Run (Runs Stages 1–5 end-to-end with real verification):
  python unlearning/pipeline.py --use_proxy --top_k 4

  # Option B: Hazardous Knowledge Unlearning (WMDP Biosecurity benchmark):
  python unlearning/pipeline.py --dataset wmdp --domain wmdp-bio --use_proxy

  # Option C: Real Model Run (when model weights are located in model/SmolLM2-135M-tofu):
  python unlearning/pipeline.py --model_path model/SmolLM2-135M-tofu --forget_split forget01 --retain_split retain99

Why we use it:
  Executes the 5-stage CASU algorithm:
    1. Ingestion (TOFU, WMDP, or MUSE)
    2. Stage 1: Mechanistic Localization (Taylor attribution)
    3. Stage 2: Causal Validation (do-calculus intervention)
    4. Stages 3 & 4: PPO Policy & Selective Updates (calibrated suppression & AdamW)
    5. Stage 5: Empirical Verification (Min-K% MIA attack, relearning slope, SVD PCA)
  Also exports a sparse parameter delta (casu_sparse_delta.pt) proving 98%+ frozen weights.


STEP 3: Run Master Evaluation & Privacy Attack Benchmarks
--------------------------------------------------------------------------------
Commands:
  # Benchmark the unlearned checkpoint:
  python evaluation/benchmark_eval.py --model_path checkpoints/llama_casu_unlearned

  # Fast CPU verification benchmark:
  python evaluation/benchmark_eval.py --use_proxy --max_samples 10

Why we use it:
  Measures formal scientific metrics including:
    • Exact Match (EM) & ROUGE-L F1 (Target: 0.0%)
    • Retain Accuracy & Language Utility
    • Min-K% Membership Inference Attack (MIA) Defense AUC (Ideal: 0.50)
    • Relearning Recovery Resistance Score & Slope
  Saves results to evaluation/benchmark_results.json.


STEP 4: Check Model Memorization (Pre-Unlearning Verification)
--------------------------------------------------------------------------------
Command:
  python scripts/check_memorization.py --model_path model/SmolLM2-135M-tofu

Why we use it:
  Confirms that the base model actually memorized the forget set (~90%+ recall)
  before running unlearning (only needed when inspecting a trained base model).
